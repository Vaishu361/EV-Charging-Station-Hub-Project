# EV Charging Station Hub Project

A comprehensive python-based system built to manage electric vehicle (EV) charging hub operations efficiently. This project provides dual structural panels to separate administrative controls from everyday user features.

# Key Features

* Admin Panel: Complete system configuration management, user data tracking, and station monitoring.
* User Panel: Dynamic controls for filtering charging hubs, sorting available slots, and locating stations.
* Core CRUD Operations: Seamless Create, Read, Update, and Delete actions for data management.
* Data Organization: Advanced filtering and sorting mechanics to handle hub operations fluidly.

# Technology Stack
* Language: Python
* Database: MySQL
* Environment: VS Code
